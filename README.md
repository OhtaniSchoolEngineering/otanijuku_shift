# 大谷塾 シフト（教員用の簡易ビューア）

大谷塾カレンダーの担当シフトだけを、スマホからさっと確認するための小さなWebアプリです。
**閲覧専用**で、担当の変更はこれまでどおり教員用ダッシュボードから行います。

大谷塾アプリ本体（GAS）とは別に、**固定のURL**で公開します。そうすることで

- 一度ログインすれば、次回からは**自動でログイン**されます
- **ホーム画面に追加**すると、アプリのアイコンから全画面で起動します（PWA）
- 圏外でも、前回見た内容がそのまま表示されます

という3点が実現できます。GASのWebアプリはURLが実行のたびに変わるため、この3つはどれもできません。

---

## 中身

| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（これ1つで動きます） |
| `manifest.webmanifest` | ホーム画面に追加したときの名前・アイコン・起動方法 |
| `sw.js` | 圏外でも開けるようにする仕組み（Service Worker） |
| `icon-180.png` / `icon-192.png` / `icon-512.png` | アイコン |

## 置きかた（GitHub Pages）

### 1. リポジトリを作って、ファイルを置く

1. GitHub で新しいリポジトリを作ります（例：`otani-shift`）。**Public** にしてください。
2. このフォルダの中身（`index.html` `manifest.webmanifest` `sw.js` `icon-*.png`）を、
   リポジトリの**一番上の階層**にアップロードします。`README.md` は入れても入れなくても構いません。

### 2. GitHub Pages を有効にする

1. リポジトリの **Settings** → 左メニューの **Pages**
2. **Source** で `Deploy from a branch` を選ぶ
3. **Branch** を `main` ／ フォルダを `/ (root)` にして **Save**
4. 数分待つと `https://<ユーザー名>.github.io/otani-shift/` で開けるようになります

### 3. Firebase にドメインを許可する（これをしないとログインできません）

1. [Firebase Console](https://console.firebase.google.com/) → プロジェクト **otanijuku-app**
2. **Authentication** → **設定**（Settings）タブ → **承認済みドメイン**
3. **ドメインを追加** を押して `<ユーザー名>.github.io` を入力して保存

> この手順を飛ばすと、ログインのときに `auth/unauthorized-domain` というエラーが出ます。
> アプリの画面にも、その旨のメッセージが出るようにしてあります。

### Netlify を使う場合

Netlify のダッシュボードにこのフォルダをドラッグ＆ドロップするだけでも公開できます。
その場合も **3.** は必要で、`<好きな名前>.netlify.app` を承認済みドメインに追加してください。

## 先生のスマホへの入れかた

公開したURLを先生に送り、それぞれの端末で一度だけ次の操作をしてもらいます。

**iPhone（Safari）**
1. URLを Safari で開く（※ Chrome ではなく Safari で開いてください）
2. 下の共有ボタン → **ホーム画面に追加**
3. ホーム画面のアイコンから開いて、一度だけ Google ログイン

**Android（Chrome）**
1. URLを Chrome で開く
2. 右上のメニュー → **ホーム画面に追加**（または「アプリをインストール」）
3. アイコンから開いて、一度だけ Google ログイン

> iPhone は、通常のSafariのタブのままだと7日間使わないうちにログイン状態が消えることがあります。
> **必ずホーム画面に追加して、そのアイコンから使ってください。** ホーム画面のアプリは専用の保存領域を持つため消えません。

## 画面の見かた

日曜〜土曜の**7列のカレンダー**で、1か月を一度に見られます。

枡の中は、限られた幅に収めるため担当者を**名字の1文字**で表しています。

| 表示 | 意味 |
|---|---|
| `後 小` | **後半**の担当（塗りつぶしのチップ） |
| `不 横 谷` | **不在**の先生（点線のチップ） |
| 表示にない先生 | **前半**の担当 |
| 斜線＋「閉塾」 | 閉塾日 |
| 「担当なし」 | 開いているが、担当者が全員不在の日（土曜など） |
| 日付が朱の丸（塗り） | 今日 |
| 日付が朱の丸（枠だけ） | 休講・長期休暇 |
| 右下の朱の点 | 備考あり |

**日付をタップすると、下のカードにその日の詳細**（前半／後半／不在の全員の名前と備考）が出ます。
起動したときは今日が選ばれています。

- `‹` `›` で月を移動、`今日` で今月に戻ります
- `↻` で手動更新。アプリに戻ってきたときにも自動で更新します
- 右上に「保存分」と出ているときは、通信ができず端末に保存した内容を表示しています

---

## 更新のしかた

`index.html` を直したら、**`sw.js` の `CACHE_NAME` の数字を1つ上げて**（`otani-shift-v1` → `otani-shift-v2`）から
両方をアップロードしてください。番号を上げないと、古い画面が残り続けることがあります。

## 気をつけること

- **シフトの決まりごと（担当者6名・曜日ごとの既定シフト）は、`index.html` の中にも書いてあります。**
  `otanijuku_app/calendar_common.html` の `PaperCal` を直したときは、こちらも同じように直してください。
- リポジトリを Public にすると `index.html` の中の Firebase の `apiKey` が見えますが、これは公開してよい識別子です
  （大谷塾アプリ本体でも同じものがブラウザに配信されています）。データを守っているのは Firebase のセキュリティルールで、
  塾のメンバーとして登録された Google アカウントでログインしない限り、シフトも含めて何も読めません。
- 書き込みは一切しません。万一このURLが外に出ても、シフトを書き換えられることはありません。
